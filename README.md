# Daily-script
Store some simple scripts used daily here

### format_to_txt
A simple Windows batch script that batch renames file extensions to .txt in the current directory. Used to convert code files that cannot be uploaded to AI into txt for uploading
1. Download / Copy the batch script (.bat file)
2. Place the script in the target folder where you want to rename files
3. Double-click to run the script
